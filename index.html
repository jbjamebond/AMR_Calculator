รุ่นมอเตอร์ (Model) ความเร็ว Fdrive / Fgrip ขนบนรถสูงสุด ลาก (มอเตอร์ / เกาะพื้น) ลากจูงจริง ตัวจำกัด (Limiting Factor)
สมการวิศวกรรมและหลักการเช็กล้อฟรี (Engineering Equations & Traction Physics) ▼
1. ความเร็วและแรงฉุดมอเตอร์ (2-Wheel Drive)
Nw = Nm / i
v = (π × (D / 1000) × Nw) / 60
T_wheel = Tm × i × (η / 100)
F_drive = (2 × T_wheel) / ((D / 2000) × SF)
2. Mode 1: โหลดขนบนรถสูงสุด (Carrying Only)
f1 = g·sin(θ) + g·μ_r1·cos(θ) + a
m_carry = (F_drive / f1) − m_AMR
Grip Check: μ_s·cos(θ)·(W_drive/100)·g ≥ f1
3. Mode 2: โหลดลากจูงสูงสุด (Towing Only)
f2 = g·sin(θ) + g·μ_r2·cos(θ) + a
m_tow_motor = (F_drive − m_AMR·f1) / f2
F_traction_max = μ_s · m_AMR · g · cos(θ) · (W_drive/100)
m_tow_trac = (F_traction_max − m_AMR·f1) / f2
m_tow_effective = min(m_tow_motor, m_tow_trac)
4. การแก้ปัญหาล้อฟรีด้วยน้ำหนักถ่วง (Ballast)
m_ballast = [F_drive / (μ_s·g·cos(θ)·(W_drive/100))] − m_AMR

หาก F_drive > F_traction_max ล้อขับเคลื่อนจะหมุนฟรีก่อนถึงแรงบิดพิกัดของมอเตอร์ ต้องเพิ่มน้ำหนักกดทับหรือเพิ่ม μ_s
